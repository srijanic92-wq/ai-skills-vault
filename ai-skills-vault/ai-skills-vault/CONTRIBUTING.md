# Contributing

Thanks for improving the AI Skills Vault.

## Before adding a skill

- Give it one clear purpose.
- Use a short, descriptive folder name.
- Add a `SKILL.md` file with YAML frontmatter containing `name` and `description`.
- Write instructions as actionable steps.
- Include input requirements, output expectations, and quality checks.
- Avoid hard-coding claims that may become outdated.
- Never include API keys, passwords, private client data, or confidential documents.

## Suggested skill structure

```text
skill-name/
├── SKILL.md
└── references/       # Optional supporting material
```

## Quality checklist

- [ ] The skill has a clear trigger and purpose.
- [ ] The workflow is specific and repeatable.
- [ ] It asks for missing critical information rather than guessing.
- [ ] It distinguishes verified facts from assumptions.
- [ ] The output format is clear.
- [ ] The instructions have been tested on at least one realistic task.
